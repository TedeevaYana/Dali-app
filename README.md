# Dali-app — мобильное приложение для изучения произведений искусства

## О проекте
Мобильное приложение, которое помогает пользователям изучать произведения живописи через интерактивный формат «просмотр → тест». Приложение разбито на логические разделы по направлениям в искусстве (сюрреализм, импрессионизм, барокко, ренессанс и т.д.), что позволяет изучать шедевры порционно, не перегружая память. 

## Целевая аудитория
- Студенты творческих вузов и школьники
- Люди, интересующиеся искусством
- Посетители музеев, желающие подготовиться к выставке

## Основной функционал (MVP — Минимально жизнеспособный продукт)

1. **Раздел «Направления» (Главный экран)**
   - Список направлений живописи в виде карточек или списка
   - Отображение названия направления и, опционально, краткого описания
   - При нажатии на направление происходит переход к экрану картин

2. **Раздел «Картины» (Галерея направления)**
   - Внутри выбранного направления пользователь листает карточки картин
   - На каждой карточке отображается:
     - Изображение картины
     - Название произведения
     - Имя автора
     - Год создания
     - Музей, в котором хранится картина (например, «Лувр, Париж»)
   - В конце галереи находится кнопка перехода к тесту

3. **Режим «Тест» (Проверка знаний)**
   - После просмотра картин направления пользователю предлагается пройти тест
   - **Формат теста**: Вопросы с вариантами ответов (например, «Кто автор этой картины?» или «В каком музее хранится эта картина?»). Показывается изображение и 3-4 варианта ответа
   - **Обратная связь**: Мгновенная проверка (подсветка правильного/неправильного ответа при нажатии)
   - **Результат**: По окончании теста выводится статистика (например, «Вы ответили правильно на 8 из 10 вопросов») и кнопка «Пройти еще раз» или «Выбрать другое направление»
